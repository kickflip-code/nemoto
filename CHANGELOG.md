# Changelog

## [1.0.0-beta.1] - Unreleased

First planned public Windows x64 Core beta, published under Kickflip Code. Local process mapping, resources, Journal, import/export, themes, optional local AI and the external plugin host are included. No plugin packages are bundled.

Internal components, styles, types and source tooling use Nemoto names; existing file, package and device-storage identifiers remain compatible. Public author/copyright metadata uses Kickflip Code. New support-bundle filenames use `nemoto-plugin-diagnostics-<timestamp>.json`.
